# 総合ルール Version 15.00

プロジェクトレヴォリューション 総合ルール Version 15.00（ＰＲＬＬＰ、ルール適用開始日
2009 年 12 月 22 日）の全文。この実装が従う唯一の拠り所であり、原文は PRLLP の著作物である。

## 引用の書き方

テストやコードから条を参照するときは、`index.json` の `citation` と同じ文字列を使う（ADR-0006）。

```ts
// 総合ルール 第2部 第21章 1
```

- 章ごとに 1 ファイル。ファイル名は `<部>-<章>-<章名>.md`
- 条番号は `1` / `1-1` / `1-1-1` / `1-5-a` に**正規化してある**。原文は `1.` `1．` `1－1.`
  `1－1．` が混在しており、参照する側が毎回このゆれを解釈しないで済むようにするため
- 【例】は引用ブロックで、直前の条に属する

## index.json

478 条項の一覧。本文は持たない。「総合ルールの何条を実装・検証したか」を数えるためのもの。

| フィールド | |
| --- | --- |
| `citation` | `第2部 第21章 1`。テストに書く文字列と一致する |
| `part` / `chapter` / `clause` | 分解した値。`clause` は番号を持たない条では空 |
| `chapterTitle` | 章名 |
| `file` | 本文があるファイル |
| `examples` | その条に属する【例】の数 |

【例】は全体で 87 個ある。PRLLP 自身が書いた「この状況ではこうなる」の記述なので、そのまま
受け入れテストに写せる（ADR-0006）。

## 扱い方

- ここが原本である。抽出時の誤りを見つけたら Markdown を直し、あわせて `index.json` を直す
- **本文の意味を変えない。** 直してよいのは抽出の誤りだけで、要約・言い換え・現代語化はしない。
  裁定でもめたときに原文として使えなくなる
- 表紙・目次・更新履歴は収録していない
