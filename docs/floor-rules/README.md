# フロアルール Version 1.12 第2部

ディメンション・ゼロ／プロジェクト レヴォリューション 汎用フロアルール Version 1.12（ルール適用開始日
2007 年 6 月 4 日、最終更新日 2010 年 11 月 25 日。最終版）のうち、**第2部「プロジェクト レヴォリューションに
関する規定」** の全文。原文は ＤＰＡ（ディメンション・ゼロ プレイヤーズ・アソシエーション）と
ＰＲＬＬＰ（プロジェクト レヴォリューション有限責任事業組合）の著作物である。

総合ルールが外へ投げた判定（第3部 第1章 3-1〜3-3）の先がここにある。総合ルールに加えて、この
第2部も実装の拠り所になる（ADR-0024）。

## 「第2部」がどれを指すか

原文は共通規定と個別規定の 2 段に分かれている。

| | 中身 | ここに置いたか |
| --- | --- | --- |
| 序文 | フロアルールの意義 | 置いていない |
| 共通規定 第1部〜第4部 | 大会運営者・参加者、大会運営、反則と罰則、罰則例索引 | 置いていない |
| 個別規定 第1部 | ディメンション・ゼロに関する規定 | 置いていない |
| **個別規定 第2部** | **プロジェクト レヴォリューションに関する規定** | **置いた（全文）** |

**この文書で「第2部」と言えば、個別規定の第2部である。** 共通規定にも「第2部 大会運営に関する規定」が
あるが、それとは別物で、置いていない。第2部が「共通項目『違反項目と罰則に関する規定』」のように共通規定を
指している箇所があるが、その参照先はこの実装が拠り所にしていないので置かない。

表紙・目次・制作・更新履歴も収録していない。

## 引用の書き方

テストやコードから条を参照するときは、`index.json` の `citation` と同じ文字列を使う（ADR-0006 / ADR-0023）。
総合ルールと違い、**版まで含めた文字列が `citation` になっている**。

```ts
// フロアルール Version 1.12 第2部 第1章 1-1
```

- 章ごとに 1 ファイル。ファイル名は `<部>-<章>-<章名>.md`
- 条番号は `1` / `1-1` / `3-4-(2-1)` に**正規化してある**。原文は `１．` `２，` `１－１．` `３－１.` `(2-1)` `（１）`
  が混在しており、参照する側が毎回このゆれを解釈しないで済むようにするため。丸括弧の段は、上の条の番号に
  `-` でつないだ（原文の `３－４．進行` の下の `(2-1)` は `3-4-(2-1)`）
- 例は引用ブロックで、直前の条に属する。総合ルールの【例】と違い、原文は「例）」と書いている

## index.json

39 条項の一覧。本文は持たない。「フロアルールの何条を実装・検証したか」を数えるためのもの。
`docs/rules/index.json` と同じ形で、フィールドは同じ意味である。ただし `citation` は上のとおり版を含む。

## 扱い方

- ここが原本である。抽出時の誤りを見つけたら Markdown を直し、あわせて `index.json` を直す
- **本文の意味を変えない。** 直してよいのは抽出の誤りと条番号の表記だけで、要約・言い換え・現代語化は
  しない。裁定でもめたときに原文として使えなくなる。カード名・型番を含む例も原文のまま置いてある
- 原文の PDF は文字コードが壊れていて、そのままではテキストにならない。復元した文字列を描画した画像と
  突き合わせて確かめてある
- 原文は行の折り返しで空白が読み取れない箇所が 1 つある（第2章 1 の「プロジェクト」と
  「レヴォリューション」の間）。文書の他の箇所がすべて空白を入れて書いているので、それに揃えた
