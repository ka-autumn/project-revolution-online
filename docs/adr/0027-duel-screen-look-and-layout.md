# 対戦画面の見た目を、明るい 1 つのテーマで組み直す

Issue #207（画面全体の見た目を今風に揃える）のうち、**対戦画面から着手する。** 名前を決める画面・ロビー・デッキ構築は、あとから同じ方向に揃える。

見た目だけを変えるつもりで始めたが、並べ方まで組み直すことにした。Issue の「変えないこと」にあった「並べ方や操作の流れ（何をどこで押すか）」のうち**並べ方は、開発者の判断で取り下げた。** 並べ替えに伴うテストの直しは、必要な手間として受け入れる。押せない手を出さない・読み上げに名前を付ける、という決まりはそのまま守る。

## 決めたこと

### 効かせる範囲：対戦画面の外枠の内側だけ

ボタン・入力欄・枠線・色は、画面をまたいで `client` の `style.css` 1 枚で共有している（`:root` の変数、`.choice__button` や `.confirm` のような共通のクラス、素の `button` 要素）。**これらには触らない。** 対戦画面の外枠にクラスを付け、新しい色・余白・部品の見た目は、その外枠の内側に置いた変数とクラスで作る。

- 他の画面は、今の見た目のまま残る。揃えるときは、この外枠の中の設定を外へ広げる。
- 確認の小窓やカードの詳細のように対戦画面と他の画面の両方で出るものは、対戦画面の中でだけ新しい見た目になる。揃うまでの間の食い違いとして受け入れる。

### テーマは 1 つ

明るい地・暗い地の切り替えは持たない。対戦画面の外枠では `color-scheme` を `light` に固定する（`:root` の `light dark` は他の画面のために残す）。

将来、プレイヤーごとに背景などを差し替えられるようにする余地がある。そのときは外枠の変数を差し替えれば済むように、色は外枠の変数から引く。

### 地と配色

- **地は明るい金・橙の光条。** 中心が白く、外へ向かって金から橙になる放射状のグラデーションに、白い光の筋を重ねる。カードの裏面の雰囲気に寄せたもの。
- **パネルはクリームの半透明に金の縁。** 見出しは焦げ茶の明朝体（游明朝など、手元にある字体。外部の字体は読み込まない）。
- **自分は青、相手は赤。** プレイヤーの枠・置き場のまとまり・ログの印・カットインで使う。
- 角丸はパネル 12px・小さな部品 7px。一番よく押す「フェイズ・ステップを進める」手だけ、金の地で目立たせる。

### 並べ方

画面を 3 列に分け、画面の高さにぴったり収める（ページ全体はスクロールさせない）。

- **左の列**：上から、相手のプレイヤーの枠、操作パネル（ターン・優先権・フェイズの一覧・行える手・部屋を出る口）、自分のプレイヤーの枠。
- **真ん中の列**：上から、相手の手札、進行中の手順の帯、盤面、自分の手札。
- **右の列**：操作ログ、カードの詳細。

プレイヤーの枠には、立ち絵の場所（胸から上のシルエット）、名前、ダメージを置く。パートナーバトルのときだけ、枠の右にパートナーのカードを置く（1 枚しか無いので枚数は出さない）。それ以外の対局では、パートナーの場所ごと詰める。

自分の表示名を出すため、`席についた`（`ToClient`）に `own` を足す。**画面は自動で配られ、サーバは手でデプロイする**ので、サーバより先に画面だけが新しい時間ができる。古いサーバは `own` を送らないので、届かなければこの端末が名前を決める画面で入れた名前で補う（`room.occupants ?? []` と同じ備え）。

フェイズの一覧は、6 つのフェイズを並べ、済んだもの・今のものを見分けられるようにする。

**進行中の手順の帯（バトル・スマッシュ判定）は、出ていないときも高さを取っておく。** 帯が出たときに盤面が上下に跳ねないようにするためと、盤面を常に縦いっぱいに広げるためである。バトルが起きているスクエアには、上端にも「バトル中」の帯を出し、枠を赤く光らせる。

#### 盤面

バトルスペースの 3×3 を狭め、その両脇と上下に置き場を並べる。**相手の側は自分の側と点対称にする**（向かい合って座った卓の見え方）。自分から見て：

| 行 | 左の脇 | | 3×3 | 右の脇 |
| --- | --- | --- | --- | --- |
| 1 | ［相手：リムーブ｜捨札］ | ［相手：スマッシュ｜エネルギー（1:2）］ | | |
| 2 | 相手の山札 | 敵エリア | □□□ | 相手のトラップ |
| 3 | バンク | 中央エリア | □□□ | 誘発した能力 |
| 4 | 自分のトラップ | 味方エリア | □□□ | 自分の山札 |
| 5 | ［自分：エネルギー｜スマッシュ（2:1）］ | | | ［自分：捨札｜リムーブ］ |

- ［ ］は枠で囲んだまとまり。エネルギーとスマッシュのまとまりは、トラップの外端まで伸ばす。
- バンクと誘発した能力は、どちらも両者で共有する「解決を待つ能力」なので、盤面の真ん中の行の両脇に置く。
- **プランゾーンの枠は設けない。** プランゾーンにカードがあれば、山札の場所に、裏面のかわりにそのカードを表で見せる（プランである旨の札と山札の枚数を添える）。有る・無しで山札の位置は動かさない。
- トラップゾーンに置けるのは 1 枚までなので、1 枚分だけ見せる。
- 山札・捨札・リムーブは、一番上の 1 枚と枚数だけを見せる束にする。捨札・リムーブは、束を押すと中身の一覧が開く（後述）。
- エネルギーとスマッシュのカードは重ねて並べる。**スマッシュのカードは、スマッシュ判定のとき以外は自分のものも裏向きで見せる。**

#### 手札

手札は扇に広げ、画面の端から上半分だけを出す（レベル・種別・カード名が読める）。乗せる・フォーカスすると全体が浮き上がる。選んでいる 1 枚は半分ほど浮いたままにする。相手の手札は、画面の上端から裏面の下半分を出す。「自分の手札」「相手の手札」の見出しは、それぞれ手札の中央、画面の端に置く。

### カードの面

カードの画像は出さない（Issue の「やらないこと」）。かわりに、文字と図で面を組む。

- **地は上が白、下がカードの色のグラデーション。** 白のカードは下を薄い灰色にし、文字を黒にする。将来はこの下にカードのイラストを敷き、このグラデーションを半透明で重ねる想定。
- 左上にレベルアイコン、右上に種別（地はレベルアイコンと同じ色）。
- その下に名前の行。**名前の地の枠は、スター・キーワード能力のアイコンまで含め、アイコンは枠から上下にはみ出させる。**
- 下のほうに、ムーブアイコン・トリガーアイコン（右寄せ）、属性、BP（左下、半透明の黒の地）・SP（右下、カードの色の地）。BP・SP は数字だけ。
- 支配者は面の外周の色で示し、**「自分」「相手」の札はバトルスペースのカードにだけ**、右肩に付ける（ほかの置き場は置き場の側で誰のものか分かる）。フリーズで面が寝ても、札は寝た面の右肩に付き直す。
- 裏面は、金・橙の光条の中の丸に「R」。

複数の色を持つカード・無色のカードは、今のカードプールに無いので考えない。

#### アイコン

- **レベルアイコン**：色ごとに形が違う（赤＝丸、青＝八芒星、白＝六芒星、緑＝五角形、黒＝六角形）。開発者が用意した SVG をそのまま使い、リポジトリに含める。
- **スターアイコン**：名前の左に ★。スターが 2 以上なら、★ の中に赤い数字を入れる。
- **リバーススターアイコン**：緑を基調にした、逆さの ★。
- **キーワード能力のアイコン**：半透明の宝石の球に、ゴシック体で字を載せる。夢＝サファイア（青）、希望＝ルビー（赤）、幸運＝トパーズ（黄）、苦労＝暗いエメラルド（緑）。**プランゾーンに関わる 4 つ（`PlanKeyword`）だけがこの扱いで、元気・信頼・根性・勇気のような、それ以外のキーワード能力にはアイコンを付けない。** これらはカードの詳細のテキストにそのまま出る。
- **ムーブアイコン**：菱形の中に上下左右の矢印。動ける向きだけ白く、ほかは暗くする。
- **トリガーアイコン**：3×3 のスクエア。侵入の対象のスクエアは赤、ほかは濃い灰色。

キーワード能力のアイコンは、カードの詳細では名前の右に出す。小さな面では、山札の場所に見せるプランのカードにだけ、名前の下の行に出す。

どのアイコンも、読み上げに中身を持たせる（「ムーブアイコン：上・左・右」「トリガーアイコン：味方エリア・左…」「スター 2」など）。

### 状態の見せ方

- **押せるカード**は橙の縁と光、**選んでいるカード**はそれより濃くする。**置き先のスクエア**は橙の破線で囲む。どれも読み上げの名前は今どおり。
- **BP・SP が元の値から変わったとき**は、上がったら赤、下がったら青の文字にし、末尾に ▲・▼ を付ける。地は変えず、地の色と文字の色が重なっても読めるように文字に白い縁を付ける。読み上げでは元の値も伝える（「BP 4000（元は 3000）」）。
- ダメージは面の中ほどに赤い帯で出す。

### カードの詳細

**右の列、操作ログの下に固定の高さで置く。** カードの横に浮かせて出すのをやめる。

- 見た目は、カードの面をそのまま拡大し、名前の下にテキストの枠を足したもの。ムーブアイコン・トリガーアイコンはテキストの枠の中の右に置き、テキストが無くてもアイコンの高さを取る。
- 何も乗せていないときは案内だけを出す。**カードを選んでいる間は、選んでいるカードが既定になる。** 別のカードに乗せる（フォーカスする）とそれに切り替わり、外れると既定に戻る。
- 下に 1 行、補足（誰のカードか・フリーズ中か・BP や SP の変化・ダメージ）を添える。

### カードの一覧

捨札・リムーブの中身を見るため、また効果で山札などから選ぶために、**画面の上に重ねるカードの一覧**を新しく設ける。ブラウザ標準のダイアログは使わず、画面の中に重ねる。

- **見る**：捨札・リムーブの束を押すと開く。中身を並べ、「閉じる」だけを置く。
- **選ぶ**：**盤面に見えていない置き場（山札・捨札など）から選ぶときだけ使う。** 盤面のユニットを選ぶ場合は今どおり盤面・ボタンで選ぶ。**候補と盤面から押せるものが混ざる場面では一覧を使わず、今どおり番号のボタンで並べる**——一覧が盤面を覆い、盤面の候補が押せなくなるためである。「選ばない」「これに決める」を置く。
  - **一覧に並べるのは、届いた候補だけである。** 何が選べるかを決めるのはサーバで、画面はルールの判断を持たない（ADR-0010）ので、候補外のカードを薄く並べて見せることはしない——どの置き場から選んでいるかを画面が推し量る必要が出てしまう。
  - **選んだ枚数の分母は出さない。** `WireChoice` は 1 回に 1 つ答える形で、選ぶ対象の総数は通信に載らない。ここまでに答えた数（`answered`）から、何枚目を選んでいるかだけを出す。
- どちらも右の列（カードの詳細）は覆わない。一覧のカードに乗せて詳細を読みながら選べる。

### 演出

- フェイズ・ターンの切り替わりは橙の帯、効果のカットインは支配者の色の帯で、画面の真ん中を横切らせる。押せる場所は塞がない（今どおり）。
- **決着は、画面全体を暗くし、光条を背負った大きな文字と帯で出す。** 勝利は金、敗北は寒色で光条を弱める。**引き分けは、勝利とも敗北とも違う、灰色を基調にした配色にする。** 色だけに頼らないのは他の状態と同じで、「引き分け」の文字も出す。
- **決着した後の「ロビーに戻る」は、決着の帯の下、画面の中央下部に金の地で出す。** 決着した後に押すのはこれだけなのに、左の列の操作パネルの中では見つけにくかった。左の列からは外す（同じ名前のボタンが 2 つ並ぶと、読み上げで区別がつかない）。出すのは今どおり繋がっている間だけ。
- 演出の層は描き直されるたびに作り直されるので、ここでも `animation` は使わない（今のコードの方針どおり）。

## やらないこと

- カードの画像（Issue #207 の「やらないこと」）。立ち絵も画像は使わず、シルエットで置く。
- スマホの縦向き。3 列が入らないので、別の並べ方として Issue #225 で扱う。
- 名前を決める画面・ロビー・デッキ構築の見直し。

## 影響

- **画面を組む `render.ts` の DOM が大きく変わる。** 並べ方と部品が変わるので、DOM の形に頼るテスト（`render.test.ts` など）は組み直す。
- **カードの詳細を浮かせて出す仕組み（右に出すか左に出すかを決める `panelSide` など）は要らなくなる。** 詳細は右の列の 1 か所に出す。
- **表示に使うカードのデータが増える。** ムーブアイコン・トリガーアイコン・スター・リバーススター・キーワード能力は、エンジンのカードのデータにすでにある。今は一部を詳細の項目として文字で並べているだけなので、図として描けるように、項目ごとの値のまま画面まで渡す。
- **カードの一覧は新しい部品である。** 見る一覧は捨札・リムーブの束から開く。選ぶ一覧は、盤面に見えていない置き場から選ぶ候補が届いたときに出す。
