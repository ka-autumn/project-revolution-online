# AI をまず対戦相手ではなくファザとして定義する

最初に作る AI は「合法手をランダムに選ぶ」だけのものとし、その役割を強い対戦相手ではなく**ルールエンジンのファザ**と位置づける。大量の自己対戦を回すことで、合法手生成の漏れ・無限ループ・不正な盤面状態を自動で炙り出す。

ルールを完全自動で強制する以上、エンジンの穴はそのまま「打てなくなる」「盤面が壊れる」として現れる。それを人力のテストだけで見つけるのは現実的でなく、ランダム自己対戦はこの検証手段として最も安い。

## 影響

- 「合法手を列挙する」機能が、AI のためではなくエンジンの必須機能になる。
- 自己対戦を再現可能にするため、乱数はシード指定できなければならない。失敗した対戦をシードから再生できることが、この決定の価値の大半を占める。
- 盤面の不変条件（カードの総数が変わらない、など）を検査する仕組みが必要になる。
