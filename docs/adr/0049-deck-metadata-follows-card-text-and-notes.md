# デッキ構築の属性と収録情報は本文・注記の後に置く

決定日: 2026-10-21。Issue #328。開発者と決定した。

## 背景

この文書を書いた時点では、デッキ構築の詳細は、種別・数値・移動方向・属性・収録を先に並べ、その下に能力テキストと運用の注記を出していた。開発者は、属性・作品名・ブロック・収録を本文より下へ移すことを希望した。作品名・ブロックは将来の表示項目としてモックだけに残されていた。

## 決めたこと

PC・スマートフォンのデッキ構築の詳細では、基本項目と移動方向、能力テキスト全文、運用の注記、属性・作品名・ブロック・収録の順にする。本文がなければ本文の枠を出さず、注記や各項目も持つものだけを出す。

作品名・ブロックは、引き続き将来の項目として仕様書・モックに残し、未実装であることを明記する。PCの一項目ずつの行と、スマートフォンのまとめた行、名前の前のスター、面の本文欄を出さないことは維持する。

今の仕様は `docs/screens/deck-builder/spec.md`、見本は画面のモックに置く（ADR-0044）。

## 検討した選択肢

- **本文、注記、属性・作品名・ブロック・収録の順。** 本文と、その扱いを補足する注記を続けて読める。分類と収録の情報はその後にまとまる。この案を採る。
- **本文、属性・作品名・ブロック・収録、注記の順。** 移す項目を本文の直後に置けるが、注記から本文へ目を戻す距離が増えるため採らない。

## 影響

デッキ構築の右欄の読む順序が変わる。対戦画面・共有レシピの並びと、カード定義・通信の値は変えない。
