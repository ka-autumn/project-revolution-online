# 総合ルールの本文を公開リポジトリに置く

総合ルール Version 15.00 の全文を `docs/rules/` に置く。この実装が従う唯一の拠り所であり、テストが条番号でここを参照するため（ADR-0006）、参照先がリポジトリの外にあると「条番号からテストへ、テストからコードへ辿る」導線が最初の一歩で切れる。裁定でもめたときに手元の資料を各自が探しに行く状態は、ルールを完全に自動適用するという目的と噛み合わない。

ADR-0002 でカード実装を公開しないと決めたのと、方針が食い違って見える点について。総合ルールは PRLLP が誰でも読める形で配布した公式文書であり、ここではその文書を実装の根拠として引用している。カードの名前・能力テキスト・作品名は、これとは性質が異なるため、ADR-0002 のまま非公開を続ける。

## 影響

- 出典と権利者を明記する。`docs/rules/README.md` に書く。
- 条番号は保存時に正規化する。原文は `1.` `1．` `1－1.` `1－1．` が混在しており、正規化しないと参照する側が全員このゆれを解釈することになる。
- **本文の意味は変えない。** 直してよいのは抽出の誤りだけで、要約・言い換え・現代語化はしない。原文として使えなくなるため。
- 総合ルールは 2009 年の Version 15.00 が最終版であり、以後改訂されない。このディレクトリは実質一度書いたら変わらない。
