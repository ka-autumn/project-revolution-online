# 誰のターンとも書かれていない「ターンの終わり」は、作成されたターンの終わりにだけ誘発する

決定日: 2026-11-03。開発者と決定した。

## 背景

「このカードがスクエアから捨札に置かれた時、そのターンの終わりに、〜する」のように、誰のターンとも書かれていない「ターンの終わり」に誘発する誘発型能力を作成するテキストを実装したい。

作成された誘発型能力が誘発するできごと（`CREATED_TRIGGERS`）は、いまは「あなたのターンの終わり」だけである。相手のターンに作成された能力が、その相手のターンの終わりに誘発することを表現できない。

後のエキスパンションにも、誰のターンとも書かれていない「ターンの終わりに、〜する」で誘発型能力を作成するテキストが 8 枚ほどある。トラップとして相手のターンに使われるものもある。

## 決定事項

- **`CREATED_TRIGGERS` に「ターンの終わり」を追加する。** 誰のターンかを問わない。テキストの「そのターンの終わりに」と「ターンの終わりに」は、どちらもこれで表現する。
- **能力が作成されたターンを覚え、そのターンの「ターンの終わり」でだけ誘発する。** 誘発しないままそのターンが終わったら、能力は取り除く。取り除いたことはログに積まない（同 4-1 で消滅した時と同じ）。
- 能力が作成されたターンの番号は、通信には含めない。いまの「あなたのターンの終わり」の能力の動きは変更しない。
- **ほとんどの場面では、「次に来るターンの終わり」と同じ動きになる。** ターンの終わりの処理の途中で能力が誘発すれば、リカバリーフェイズはやり直しになり（総合ルール 第3部 第10章 4）、「ターンの終わり」がもう一度来るためである。異なるのは、「ターンの終わり」が済んだ後に、能力の誘発ではない行動（トラップの発動など）で作成された場合だけである。この時、能力は誘発せずに取り除かれる。テキストは作成したそのターンの終わりを指しており、そのできごとはもう起こらないので、誘発しない（同 第4部 第3章 4）。
- **015・069 は、相手のターンに捨札に置かれれば、その相手のターンの終わりに手札に加わる。** テキストの「そのターン」は捨札に置かれたターンを指す、と読む。上の決定から、そのまま決まる。

## 検討した選択肢

- **次に来るターンの終わり（誰のターンでも）。** 作成されたターンを覚える必要が無い。しかし、「ターンの終わり」が済んだ後にトラップで作成された能力が、次のターンの終わりまで持ち越される。テキストの「そのターン」と食い違う。採用しない。

## 既存の決定との関係

- **ADR-0036。** リカバリーフェイズのやり直しを実装したのは ADR-0036 である。この決定は、そのやり直しの中で「ターンの終わり」がもう一度来ることを前提にしている。
- **ADR-0018・ADR-0053。** 「あなたのターンの終わり」の能力の動きは変更しない。「ターンの終わり」を使うのは、今回実装するカードだけである。このため、記録済みの対戦を打ち直した結果は変化しない。
- 「次の相手のターンの終わりまで、〜した時に誘発する」のような、期限を持つ作成された誘発型能力（同 4 の 2 文目）とは、期限という別の軸である。この決定は、その設計を制約しない。

## 影響

- engine の作成された誘発型能力が、作成されたターンを持つようになる。通信のデータと画面は変更しない。
- 015 は、この決定と ADR-0057 で実装できるようになる。069 は、ADR-0057 の「影響」に書いた別の決定が残る。

## 実装

- 値: `CREATED_TRIGGERS` の `'ターンの終わり'`
- 作成されたターンの番号: `CreatedAbility.createdIn`（`DuelState.turn.number`）。「ターンの終わり」の能力だけが読む。通信の `VisibleCreatedAbility` には含めない
- 取り除く所: ターンが変わる時（`progress.ts` の `beginNextPhase`）。そのターンのうちに誘発しなかった「ターンの終わり」の能力を、すべて取り除く
