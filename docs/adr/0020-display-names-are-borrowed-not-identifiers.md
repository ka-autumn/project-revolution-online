# 表示名は呼ぶためのもので、人を指す識別子ではない

ロビーと対戦相手のところに、人の表示名を出す（#177 の 3 段目）。**その名前は重複を許し、いつでも変えられ、記録には焼き付けない。**

ADR-0019 は「本人が付けた表示名を預かる」ところまで決めて、決まりそのもの（重複を許すか、変えられるか、使えない文字）を意図的に空けた。**名前を人に見せるまでは、決めなくてよかったからである。** 見せる以上、ここで決める。

## 人を指しているのは行番号である

**席に使う識別子は身元の行番号で、そこはログインから来ている**（ADR-0019、`store.ts` の `seatedAs`）。表示名はそこに乗るだけで、誰であるかを決めてはいない。

**だから重複を許す。** 一意にすると、**変わりうるものが 2 つ目の識別子になる。** 人を指すものが 2 つあれば、食い違ったときにどちらが正しいかを決める場所が要る——ADR-0010 が「サーバと画面のどちらが正しいか」について書いたのと同じ形の問題を、識別子の側で作ることになる。

**退会の口が無いことも効く**（ADR-0019 が決めていない）。一意にすれば、一度取られた名前は永久に空かない。**誰も使っていない名前を、誰も名乗れないという状態を作る。**

**引き換えに、同じ名前の人が並びうる。** 紛らわしくはあるが、**名前で席は決まらない**ので、なりすませても起きるのは「誰と打っているかの勘違い」までである。ADR-0009 が畳まれた今、名乗ることと座れることは別のことになっている。**見分けるための符号（`かずお #12` のような）は先に作らない。** 見分けが要る場面が実際に出てから足す。

## 変えられる。そして記録には残さない

本人が付けたものなので、直せる。**回数や間隔の制限は設けない**——それは迷惑対策であり、ADR-0019 が決めなかったものをここで先取りしない。

**対戦の記録に名前を写し取らない。** `duels` に入っているのは行番号だけで、表示名はそこから引く。**名前を変えれば、過去の対戦もいまの名前で出る。**

これは ADR-0018 の形から出てくる。**残すのは「そこへ至った入力」であり、表示名は入力ではない。** デッキとシードと行動の並びがあれば同じ盤面が作り直せるが、そこに名前は要らない。写し取れば、**同じ人の対戦が名前を変えた時点で 2 人ぶんに見える**ことになる。

## 決まり

**受け取ったものをそのまま置かない。** 読み方を書く場所は 1 つ（`server` の `name.ts`）で、置き場に入る前に必ずそこを通る。

- **前後の空白を取り除いた結果が、1 文字以上 20 文字以下**でなければ断る。数えるのはコードポイントで、UTF-16 の長さではない——絵文字 1 つが 2 文字ぶんとして数えられると、上限が文字によって変わる
- **制御文字・改行・双方向制御文字**（U+202A–202E、U+2066–2069）を含むなら断る。**表示の向きを操られると、名前の外まで壊せる**
- **NFC に正規化して置く。** 濁点の合成の有無で、見た目が同じ別の文字列が 2 つできる
- **見た目が似た別の文字（ホモグリフ）は弾かない。** 弾き始めると際限が無く、それは迷惑対策である
- **同じ表示名の人がすでにいても通す**（前節）

**上限を 20 にしたのは、部屋の名前（24）より短くてよいからである。** 部屋の名前は説明を兼ねるが、表示名は呼ぶためのものである。

## 名前が無い人は、名前を決めるまで何もできない

ADR-0019 の実装より前からいる身元には表示名が無い。**名前の列は「まだ決めていない」を表せなければならない**ので、NULL を許す。

**繋ぎはする。名前を決めるまで、ほかのことを受け付けない。** 断って閉じることもできたが、**閉じると名前を送り返す口が無くなる。** 画面とサーバは出所が違う（ADR-0019）ので、HTTP の口を新しく開けば、そこに CORS を 1 つ増やすことになる。**同じ接続の上で決めさせれば、口も増えない。**

**何を行えるかを決めるのはサーバである**（ADR-0010）。ログインしているかどうかと同じ軸に、名前を決めたかどうかも乗る。**画面は判断しない**——繋いだ結果としてサーバが「名前を決めてほしい」と言い、画面はそれに従う。

## 畳むもの

- **`WireRoom` の「そこにいる人の名乗りは載せない」。** 名乗りは席に座れる合言葉だったので、一覧に出すと誰でも他人の席に着けた（ADR-0009）。**その理由は ADR-0019 で消えている。** 座っている人の表示名を載せる
- **`席についた` の「誰と打っているか」が `'人間' | 'CPU'` だったこと。** 人間なら誰かが分かるようにする。部屋を作るときに選ぶ相手の種類（`OpponentKind`）とは別のものになる

## 影響

- **`identities` に列が 1 つ増え、置き場に初めて移行が要る。** これまでは `create table if not exists` だけで足りていた。**足りない列だけを足す形にし、`store.ts` の中に閉じる**（SQL を書くのはそこだけ、ADR-0018）
- **ロビーの中身が、部屋の様子だけでなく人の名前でも変わる。** 誰かが名前を変えれば、ロビーにいる全員に送り直される
- **表示名は置き場に入る。** ADR-0018 の「置き場に残るものは公開できないものとして扱う」に、自分で付けた名前が加わる。**ADR-0019 が預かると決めた範囲の中**であり、増えてはいない
- **手元で立てたときは、名乗り（`?participant=`）がそのまま表示名になる。** ログインの設定が無いときに名前を決めさせても、預ける先が無い（置き場を持たない立て方ができる）。**開いているかどうかを別の旗で持たない**という形（ADR-0019）はここでも同じで、**設定があるかどうかがそのまま境目になる**
