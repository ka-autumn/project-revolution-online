# 誘発型能力を与えられるようにし、移動方向の変更を継続効果の種類に追加する

決定日: 2026-11-11。開発者と決定した（#335）。

この文書は設計として先に書いた。実装した後で、実装で決定した名前を末尾の「実装」の節に追記する。

## 背景

EB1.0 の 085 は、ターンの終わりまで、味方全員に誘発型能力を与え、移動方向を変更する
（架空の例: 「ターンの終わりまで、味方全員に『このカードがバトルに勝った時、カードを１枚引く。』という能力を与え、
移動方向を↑にする」）。

期限と「味方全員」は、作成された継続効果（ADR-0036）で実装できる。実装できないのは次の 2 つである。

- 与えられる能力の種類は型で絞っていて、今は「夢」だけである（ADR-0036）。誘発の処理は、ユニットの能力を、
  カードに書かれているものから取得している。
- 移動方向を変更する継続効果が無い。ムーブアイコンを参照する所（engine の移動の判定、CPU の見積もり、画面の表示）は、
  どれもカードに書かれた値を参照している。

ムーブアイコンは、カードのデータの 1 つである（総合ルール 第2部 第2章 2）。移動方向を変更する効果の読み方を
定めた条は無い。原本のテキストは、後のエキスパンションを含めて 35 行あり、「移動方向を↑にする」のように
「にする」と書く形（約 12 行）と、「移動方向←→を与える」「得る」と書く形（約 20 行）に分かれる。
「〜を↑にする代わりに、移動方向を↑↓←→にする」と書いた行が 1 つある。

後のエキスパンションには、期限つきで能力を与える行が 83 行ある。テキストの能力が約 30 行（誘発型能力が多く、
誘発しない能力も含む）、キーワード能力が約 20 行である。

## 決定事項

### 与えられる能力

- **誘発型能力を、種類ごと与えられるようにする。** 誘発イベントは、カードに書かれた誘発型能力と同じものを使える。
  誘発の処理は、ユニットの能力を、与えられた能力を含むデータから取得するように切り替える。
- **誘発しない能力（常在型能力、まだ engine に無いキーワード能力）は、今回は与えられるようにしない。**
  その能力を参照する所を切り替えた時に、与えられる種類へ追加する（ADR-0036 の決定のまま）。
- **与えられた誘発型能力は、与えられたユニットの能力として誘発する。** 発生源はそのユニット、支配者はそのユニットの
  支配者である。カードに書かれた能力と同じ経路で、バンクに入り、解決される。
- **継続効果が終わると、能力も無くなる。** 期限が来た時と、対象がスクエアを離れた時である（ADR-0036）。
  すでに誘発してバンクにある能力は、取り除かない。
- **与える誘発型能力は、表示のための文を持つ。** 能力の効果は関数で、画面に表示できる情報を持たない。
  作成された誘発型能力（ADR-0063）と同じく、カードの実装の側が、能力のテキストを文として渡す。engine は文の中身を
  参照しない。
- **能力を与える常在型能力（ADR-0070）からも、誘発型能力を与えられるようになる。** 与える値を共有しているためである。

### 移動方向の変更

- **継続効果の種類に、移動方向の変更を追加する。** 変更の方法は種類で持ち、今回は「置き換える」だけを追加する。
- **「移動方向を↑にする」は、置き換えである。** 対象のユニットは、変更されている間、指定された方向にだけ移動できる。
  ムーブアイコンを持たないユニットも、指定された方向に移動できるようになる。原本が「にする」と「与える・得る」を
  書き分けていることによる読みで、開発者が確認した。
- **「与える・得る」（追加）は、そのテキストを実装する時に、方法を 1 つ追加する。**
- **同じユニットに複数の変更がかかる時は、発生した順に適用する**（総合ルール 第4部 第12章 5-4）。置き換えの後に
  追加が発生すれば、置き換えた方向に追加した方向が含まれる。追加の後に置き換えが発生すれば、置き換えた方向だけになる。
- **移動方向の変更は、ほかの種類の継続効果より後、ＢＰ・ＳＰの変更より前に適用する。** 支配者・テキスト・種別・属性の
  どの変更でもないので、一般的な継続効果（同 5-2 の(4)）として扱う。
- **解決した時点でスクエアにいたユニットにだけ効く。** カードのデータを変更する継続効果である（同 3-2）。
- **engine の移動の判定は、継続効果を適用した後の移動方向を参照する。** 効果に見せる盤面のビューのユニットも、
  適用した後の移動方向を持つ。

### 画面とログ

- **ログは、対象のユニットごとに 1 行にまとめる。** 与えられた能力の文、変更後の移動方向、期限を表示する。
  ログに積む継続効果の変更（`LoggedContinuousChange`）は、誘発型能力には文を、移動方向の変更には方向を持つ。
- **カードの詳細に、与えられた能力の文と期限を、枠で表示する。** 見た目は、作成された誘発型能力の枠（ADR-0063）に
  そろえる。「移動方向」の行は、変更後の値にする。
- **ムーブアイコンは、変更後の向きで描く。** 盤面の拡大表示と、カードの詳細の両方である。
- **通信のデータに、適用した後の移動方向と、与えられた能力の文を追加する。** スクエアのユニットの、適用した後のデータ
  （ＢＰ・ＳＰ・属性）と同じ所に含める。スクエアのユニットは公開情報である。
- 画面の文言と見た目は、`docs/screens/` の仕様書とモックで決定する（ADR-0044）。

### CPU

- **CPU が移動できるかを見積もっている 4 か所は、適用した後の移動方向を参照する。** 敵が移動で攻め込んでくるか
  （`forecast.ts` の 2 か所）、味方を移動させて倒しきれるか、ユニットが前へ進めるか（`scored-cpu.ts` の 2 か所）である。
- **使う前の損得の見積もり（ADR-0062）では、能力を与える効果を、今と同じく、味方 1 枚につき固定の点数にする。
  移動方向の置き換えは 0 点にする。** 与えた能力が実際に誘発しそうかは見積もらない。

## 検討した選択肢

**「移動方向を↑にする」を、追加と読む** — 対象のユニットに不利が無い。しかし、原本が「与える・得る」と
書き分けている行と区別が無くなる。採用しない。

**「バトルに勝った時」に誘発する能力だけを与えられるようにする** — 確認する範囲が小さい。しかし、切り替える処理は
同じ場所で、ほかの誘発イベントの能力が出るたびに、型の絞りを広げる変更が要る。採用しない。

**どんな能力でも与えられるようにする** — 後のエキスパンションの行がすべて表現できる。しかし、常在型能力を与えると、
継続効果どうしの依存（総合ルール 第4部 第12章 5-4）が起きる。確認できるテキストも無い。採用しない。

**誘発型能力を与える代わりに、対象を持つ作成された誘発型能力として実装する** — 今ある仕組みで実装できる。しかし、
テキストは能力を「与える」と書いていて、与えられた能力は、そのユニットの能力である。「能力を持つ」ことを参照する
テキストや、能力を失わせるテキストと、食い違う。採用しない。

**ログだけに表示する** — 通信と画面の変更が小さい。しかし、ログが流れた後は、どのユニットが能力を持つか、
なぜ横に移動できないかが、画面から分からない。採用しない。

**カードの詳細の行だけを変更後の値にし、ムーブアイコンは描き直さない** — アイコンを描く所を変更せずに済む。しかし、
詳細の行とアイコンで、向きが食い違って表示される。採用しない。

**CPU が、与えた能力が誘発しそうかまで見積もる** — 空振りが減る。しかし、バトルの勝ち負けの先読みを空回しに
組み込むことになり、バトルの損得の見積もり（#386）の範囲と重なる。採用しない。

**CPU の見積もりを 0 点にする** — 空振りが無い。しかし、CPU はこのカードを基本的に使わなくなる。採用しない。

## 既存の決定との関係

- **ADR-0036。** 与えられる能力を型で絞る決定は、そのまま使う。絞りに、誘発型能力を追加する。継続効果の種類が
  1 つ増える。
- **ADR-0063。** 表示のための文をカードの側が渡す決定を、与えられる誘発型能力にも当てはめる。
- **ADR-0068。** 移動を妨げる常在型能力の判定とは、別の判定である。移動方向の変更は、移動先の候補を決定する所に効き、
  移動を妨げる能力は、その後に判定する。CPU が移動を見積もる 4 か所は、同 ADR が挙げた所と同じである。
- **ADR-0070。** 与えられた能力の集計を共有する。能力を与える効果どうしが依存する場面は、この決定の後も無い。
  与えるのは名前を持たない誘発型能力か、誘発型のキーワード能力で、それを与える条件にするテキストが無いためである。
- **ADR-0018・ADR-0053。** 既存のカードは、誘発型能力を与える効果も移動方向の変更も持たない。誘発の処理が参照する
  データは、既存のカードでは、カードに書かれた能力と同じ結果になる（与えられる「夢」は誘発しない）。既存のカードの
  動きも、記録済みの対戦を打ち直した結果も変化しない。

## この決定が決定していないこと

- **移動方向の追加（「与える・得る」）と、常在型能力による移動方向の変更。** そのテキストを実装する時に決定する。
- **誘発しない能力を与えること。**
- **与えられた能力を失わせるテキスト、与えられた能力を参照するテキスト。**
- **CPU が、与えた能力が誘発しそうかを見積もること。** バトルの損得の見積もり（#386）と一緒に扱う。

## 影響

- 誘発の処理が、与えられた能力を含むデータを参照するようになる。
- ムーブアイコンを参照する所（engine・CPU・画面）が、継続効果を適用した後の値を参照するようになる。
- 通信のデータ、ログ、画面の仕様書とモックが変更される。
- この決定で実装できるようになるカード（EB1.0 の番号）: 085。
