# 総合ルールがフロアルールへ委ねた判定は、フロアルールの条を引く

総合ルールは、デッキの規定のいくつかを「詳細はフロアルールをご参照ください」と外へ投げている（第3部 第1章 3-1〜3-3）。**その先で決まっている判定を実装するときは、フロアルールの条を根拠として引く。** 引き方は「フロアルール Version 1.12 第2部 第1章 1-1」の形にする。

ADR-0007 は総合ルールを「この実装が従う唯一の拠り所」とした。**これはその例外ではなく、総合ルール自身が外へ投げた先を辿るものである。** 総合ルールが決めていることは、今までどおり総合ルールで決まる。

## 何が起きたか

部屋ごとに禁止／制限リストを当てるようにしたとき（#190）、同名のカードの判定に、総合ルールに書かれていない決まりが要った。

- **同名かどうかは、カード名に空白が入っているかどうかを無視して判断する。** 「松岡美羽」と「松岡 美羽」は同名である。総合ルールは「同じ日本語版のカード名を持つカード」とだけ書いていて、空白の扱いを持たない。
- **制限カードと禁止カードは、同名のカードに掛かる。** 総合ルールは禁止／制限の中身をフロアルールへ投げている。

どちらもフロアルールの第2部「プロジェクト レヴォリューションに関する規定」の 第1章 1-1 に書かれている。

## 決めたこと

- **総合ルールが外へ投げた判定は、フロアルールの条を引いて実装する。** 条番号を付ける理由は ADR-0006 と同じで、裁定でもめたときに条からテストへ、テストからコードへ辿るためである。
- **引くのは第2部（プロジェクト レヴォリューションに関する規定）だけである。** フロアルールはディメンション・ゼロと 1 冊になっていて、第1部はそちらの規定である。
- **版を書く。** フロアルールは総合ルール（ADR-0007）と同じく最終版が 1 つに決まっていて、Version 1.12 がそれである。引用には版を含め、どの文書の条かを引用そのものに残す。
- **本文は `docs/floor-rules/` に置く**（ADR-0024）。引き方を先に揃えておいたので、コメントもテストも書き換えずに辿れる。

## この決定から出てきたもの

- **同名の判定は engine の 1 か所にまとめた**（`deck.ts` の `sameNameKey`）。同名の 4 枚までと禁止／制限リストの上限の両方がそこを通る。判定を分けると、片方だけ空白を無視する形が書けてしまう。同名の扱いを変える効果を持つカードが入るときも、直すのはそこである。
- **禁止／制限リストは、カードを指す識別子ではなくカード名で名指す。** 上限は同名のカードに掛かるので、決まりの単位と書き方の単位を揃える。識別子で名指すと、名指した識別子がプールに無く、同じ名前の再録カードだけがプールにあるとき、名前を引けずに上限が当たらなくなる——リストはプールに無いカードを名指してよい（ADR-0021）ので、これは普通に起こる。

## 影響

- **拠り所が 1 つ増えた。** 総合ルールとフロアルールが食い違って見えるときは、総合ルールが外へ投げたところかどうかで読み分ける。投げていないところでは総合ルールが正である。
- **フロアルールの条番号から、本文へリポジトリの中だけで辿れる。** ADR-0007 が避けた状態は、第2部を `docs/floor-rules/` に置いたことで解消している（ADR-0024）。
- **禁止／制限リストの書き間違いは見つけられない。** 名前の表記が違う（空白以外の揺れ）と、どのカードにも一致せず黙って当たらない。プールに無い名前を許しているので、立てるときに断ることもできない。公式のカード名をそのまま写す限り起きにくい。
- **渡すモジュールの `restrictions` の `limits` は、鍵がカード名になった。** 識別子を鍵にして書いていたリストは書き換えが要る（いまは空である）。
