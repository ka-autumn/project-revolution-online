# 何枚目かは N 枚続けて選ぶ選択にだけ出し、支配者が N 枚選ぶ形は命令にする

決定日: 2026-11-01。Issue #347。開発者と決定した。

## 背景

カードを選ぶ一覧の足もとには「n 枚目を選んでいます」が出ていた。n は選択の要求の `answered`（いま選んでいる人が、この行動の中で続けて答えた数）に 1 を足したものである（ADR-0052）。

効果でカードを 2 枚選ぶストラテジーをプレイすると、1 枚目の一覧に「2 枚目を選んでいます」、2 枚目の一覧に「3 枚目を選んでいます」と出た。効果の対象より前に、コストのエネルギーを選ぶ答えがあり、それも数えるからである。

もとの原因は、エンジンから見て、効果の中の 2 回の `choose` が「2 枚続けて選ぶ」ひとまとまりであることが分からない点にある。「何枚目か」を正しく出せるのは、エンジンが N 枚続けて選ぶと知っている選択（選択の要求に `series` が載る、相手に手札を捨てさせる選択）だけだった。

## 決めたこと

### 画面は、`series` がある選択にだけ枚数を出す

- **`series` が無い選択では、「n 枚目を選んでいます」を出さない。** 分母が分からない数は、実際の枚数とずれうるので出さない。`series` がある選択は、今までどおり「{印を付けた数} / {N} 枚」を出す。
- 「ひとつ戻る」の出し分けなど、`answered` を読む場所は変えない。変えるのはラベルだけである。

### 支配者が N 枚を選ぶ形は、命令にする

- **「N 枚選び」を `choose` の繰り返しで書く代わりに、N 枚を選ぶ命令 `複数を選ぶ` を足す。** 効果に書く関数は `chooseSeveral(candidates, count)` で、選んだカードの並びを返す。
- **1 枚ずつ聞くこと、選んだものを次の候補から外すこと、`series` を載せることは、エンジンが受け持つ。** カードの側で候補を除き忘れたり、`nth`・`of` を書き違えたりできない形にするためである。答えと記録の形は変えない（候補の番号を 1 つずつ）。
- **候補が `count` 枚以下なら、聞かずに候補を全部選ぶ。** 選ぶ余地が無いためで、相手に手札を捨てさせる命令と同じ扱いにそろえる（ADR-0052）。候補が 0 枚なら何も選ばず、空の並びを返す。
- 選ぶ人は支配者だけである。選ぶ人を相手にする形、選ばないことを選べる形（「N 枚まで選び」）は、そのテキストを書く時に足す。

### ログ

選んだカードごとに、今までと同じ `選ぶ` の行を 1 行ずつ積む。ログの形も、画面のログの読み方も変えない。行の順は、1 枚選んでは置く、の繰り返しだった時と変わり、N 枚を選ぶ行が先に並んでから、置く行が並ぶ。

## 検討した選択肢

- **画面だけで出し分ける（枚数の表示をやめる）。** 変更は小さい。しかし、2 枚を選ぶ効果で、何枚選ぶのかが画面から分からなくなる。採らない（単独では）。ラベルを出さない決まりは、上のとおり併せて採る。
- **命令だけを足す。** 2 枚選びのカードは直る。しかし、効果が別々に選ぶ形（条件の違う 2 枚を 1 枚ずつ選ぶ、カードを選んでからスクエアを選ぶ）や、コストの後の選択では、ずれた数が残る。採らない。
- **`選ぶ` 命令に、省略できる `series` を足す。** 足すものは少ない。しかし、2 回の `choose` に書く `nth`・`of` と、2 回目の候補から 1 回目を除く処理が、カードの側に残る。書き違えを型で防げない。採らない。
- **候補が `count` 枚以下でも、1 枚ずつ聞く。** 記録の互換は保てる。しかし、印を全部付けるしかない一覧が出る。採らない。

## 既存の決定との関係

- **ADR-0052。** N 枚を選ぶ時の決まり（1 枚ずつ N 回、選んだものを外す、画面でまとめて選ぶ、聞かずに全部）を、支配者が選ぶ形に広げる。同 ADR の冒頭に、この 1 点を知らせる 1 行を足す。
- **ADR-0018。** 記録の形は変えない。ただし、すでに記録された対戦のうち、候補がちょうど `count` 枚の「N 枚選び」を 1 回以上聞いて答えているものは、新しいエンジンで打ち直すと答えが余る（候補が `count` 枚以下なら聞かなくなったため）。余った答えは打ち直しを止める（ADR-0053）。サーバを配り直す前に進行中の対戦が無いことを開発者が確認する流れで扱う。

## 影響

- 効果の命令が 1 つ増える。選択の要求の形は変えない。
- 書き直すカードは、EB1.0 の 071 だけ（効果の中で、テキストどおりの「N 枚選び」を `choose` の繰り返しで書いていた唯一のもの）。
- カードを選ぶ一覧の足もとから、`series` が無い選択の「n 枚目を選んでいます」が無くなる。

## 実装

- 命令: `複数を選ぶ`（項目は `candidates` と `count`）。効果に書く関数は `chooseSeveral`
