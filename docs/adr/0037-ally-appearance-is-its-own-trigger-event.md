# 味方の登場は、別の誘発イベントで受ける

「味方が登場した時、〜」という誘発型能力を書けるようにする。engine の誘発イベント「登場した時」は、登場したユニット自身の能力だけを誘発させる。スクエアにいる他のユニットが、味方の登場を見て誘発する形が無かった。

この文書は設計として先に書き、実装はその後に行った。実装で決めた名前と読み方は、それぞれの項に書き足している。

## 決めたこと

- **誘発イベントを 1 つ足す（`'味方が登場した時'`）。** プレイされたユニットがスクエアに置かれた時、これまでの「登場した時」（登場した本人の能力だけ）に加えて、同じ支配者のスクエアのユニット全員の「味方が登場した時」を誘発させる。
  - **誘発させる所は 1 か所である。** プレイされたユニットを置く所（`play.ts` の `placePlayedUnit`）が、本人の「登場した時」（`triggerAppearance`）に続けて呼ぶ（`bank.ts` の `triggerAllyAppearance`）。
  - **本人の「登場した時」と、味方の「味方が登場した時」は、同時にバンクに入る**（総合ルール 第4部 第7章 3）。どれから解決するかは支配者が選ぶ（同 第8章 1-1）。
- **登場した本人も含める。** プレイされてスクエアに置かれたユニットは、その時点でスクエアにある自分のユニット、つまり「味方」である（総合ルール 第2部 第20章 1-4-a）。「味方が登場した時」の能力を持つユニットは、自分自身の登場でも誘発する。開発者が確認した読みである。
- **きっかけは、「登場した時」のものに、登場したユニットを足した形にする。** 置かれたスクエア・プレイされたゾーン・登場したユニットを持つ。登場したユニットを持つのは、「他の味方が登場した時」（自分自身を除く）を、絞り込み（`when`）で書けるようにするためである。絞り込みは、能力を持つユニット自身も受け取るので、識別子を見比べれば足りる。「あなたのユニットがスクエアから捨札に置かれた時」と同じ作りである。
  - **きっかけの型は `AllyAppearanceOccasion` で、登場したユニットは `appeared` に持つ。** 「他の味方が登場した時」は、絞り込みで `appeared.id` と能力を持つユニット自身の `id` を見比べて書く。
  - **登場したユニットは、置かれた直後の、継続効果を適用した後の姿で渡す。** 捨札のきっかけが、置かれる直前の、継続効果を適用した後の姿を渡すのに揃えた。
  - **誘発イベントを満たすたびに 1 度ずつ誘発する**（総合ルール 第4部 第7章 6）。同じターンに味方が複数回登場すれば、その回数だけ誘発する。
- **効果でスクエアに置かれたユニットでは誘発しない。** プレイされたユニットがスクエアに置かれることだけを「登場する」と呼ぶ（同 1-4-a）。これまでの「登場した時」と同じ線引きで、実際の運用もそのとおりであることを開発者が確認した。効果で置かれたユニット自身の「登場した時」も、これまでどおり誘発しない。
- **既存の「登場した時」は変えない。**

## 検討した選択肢

**「登場した時」を全員に配る形に変え、絞り込みで分ける** — 誘発イベントの値が増えない。しかし、「登場した時」を持つ既存のカードすべてに「登場したのが自分自身」という絞り込みを足す書き換えが要る。書き忘れたカードは、他の味方の登場でも誘発し、型では見つからない。「登場した時」はいちばんよく出る誘発なので、書き忘れの機会が多い。

**「登場した時」に、配る範囲（自分だけ／味方全員）を選ぶ欄を足す** — 既存のカードを変えずに済み、値も増えない。しかし、どのできごとかを決める場所が、誘発イベントの値と範囲の欄の 2 か所になる。捨札のイベントと作りが揃わない。

誘発イベントに条件を付けた値（「味方エリアに登場した時」「プランゾーンから登場した時」など）を足していく形は、採っていない。絞り込みの軸（エリア・元のゾーン・色・レベル・属性）が組み合わせで増え、値が数えきれなくなるためで、そうした条件は能力の側の絞り込み（`ability.ts` の `TriggeredAbility.when`）で書く。今回足すのは「誰の登場か」という軸の値で、取りうるのは味方と敵くらいである。数え上げられるので、値として持つ。

## この決定が決めていないこと

- **「敵が登場した時」。** 書くテキストが出た時に、同じ作りで足す。

## 影響

- **プレイされたユニットがスクエアに置かれるたびに、同じ支配者のスクエアのユニット全員の能力を見に行くようになる。**
- **カードのテキストの書き分け（「登場した時」と「味方が登場した時」）が、そのまま誘発イベントの値の違いになる。** 取り違えても型では見つからない。
- **この決定で書けるようになる形（BR1.0 の番号）。** 味方の登場で誘発する能力（32）。効果の側は、ADR-0036 の作成された継続効果でＳＰを変える。
