# サーバを盤面の唯一の権威とする

サーバだけが完全な盤面を保持し、各クライアントには「そのプレイヤーが見てよい盤面」だけを送る。山札・手札・裏向きのトラップ・スマッシュは非公開情報であり、全体をクライアントに送ればそれだけでカンニングが成立するため。

クライアントも同じルールエンジンを、自分視点の盤面に対して動かす。用途は先読み表示と入力の妥当性チェックであって、権威ではない。

## 影響

- 「完全な盤面」から「ある視点の盤面」を導く射影が、最初から必要になる。後付けできる構造ではないため、最初の実装から組み込む。
- クライアント側のエンジンは、非公開情報が欠けた盤面でも動かなければならない。エンジンの入力型はこれを表現できる必要がある。
