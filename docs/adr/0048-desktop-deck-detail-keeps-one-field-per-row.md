# PC のデッキ構築の詳細は一項目ずつにする

決定日: 2026-10-21。Issue #328。開発者と決定した。

## 背景

この文書を書いた時点では、ADR-0047 に従い、デッキ構築の PC とスマートフォンの詳細で種別・レベル・色、ＢＰ・ＳＰをそれぞれ 1 行にまとめていた。PC の詳細は左列に置くため情報欄の横幅が狭く、複数の項目をまとめると値が折り返されて読みにくかった。

## 決めたこと

PC のデッキ構築の詳細では、種別・レベル・色・ＢＰ・ＳＰをそれぞれ独立した行に戻す。スマートフォンの詳細シートでは従来のまとめ方を維持する。

名前の前のスター・リバーススターは残す。スター・キーワードなどの説明行を再び足すことはしない。面の本文欄を出さないこと、全文・注記・収録の表示も維持する。

今の仕様は `docs/screens/deck-builder/spec.md`、見本は画面のモックに置く（ADR-0044）。

## 検討した選択肢

- **PC も複数項目を 1 行にまとめ続ける。** 行数を減らせるが、横幅の狭い情報欄で値が折り返されるため採らない。
- **PC は一項目ずつ、スマートフォンはまとめる。** 行数は PC だけ増えるが、各項目を読みやすくできる。この案を採る。

## 影響

情報欄の行のまとめ方を PC とスマートフォンで分ける。表示幅が切り替わったときは、その幅に対応する行に描き直す。対戦画面・共有レシピには適用しない。
