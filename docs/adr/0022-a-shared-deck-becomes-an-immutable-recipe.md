# 共有したデッキは、手を離れた不変のレシピになる

組んだデッキを人に渡せるようにする。**共有すると、そのときの中身を写し取った不変のレシピができる。** ゲームの中ではコピーして自分のデッキにでき、外では誰でも読める。**ただしカードのテキストは、ログインした人にしか出さない。**

デッキそのものは ADR-0021 にある。ここで決めるのは、それが持ち主の手を離れるところである。

## デッキとレシピは別のものである

**デッキは持ち主のもので、直せる。レシピは写し取ったもので、変わらない。**

共有を「自分のデッキに見せる旗を立てること」にすると、**デッキを直した瞬間、渡した相手が見ているものが変わる。** 外へ出た URL は取り消せないので、「使ってみて」と渡したものが翌日には別のデッキになっている。**渡したものが変わらないことは、渡す行為の前提である。**

**写し取ったものが変わらないだけで、カードの姿までは焼き付けない**（ADR-0021）。カードの実装が直れば、レシピの見え方も直る。**不変なのは「何が何枚か」であって、カードそのものではない。**

## 決めたこと

### 何が起きるか

- **共有すると、中身を写し取ったレシピが 1 つできる。** 元のデッキを直しても、配ったものは変わらない。
- **同じ中身のレシピは 1 つに決まる。** デッキは保存するときに並びが揃うので（ADR-0021）、中身から鍵を決められる。**同じものが二重に並ばない。**
- **共有には 2 段階ある。「リンクを知っている人だけ」と「一覧に載せる」。** 身内に渡すつもりのものが新着に流れることを、取り消しではなく設定で防ぐ。
- **共有は取り消せる。** URL は死ぬ。**すでにコピーした人の手元のデッキは、その人のものなので残る。**
- **コピーできるのは 3 つ。** 開発者が置いた既製デッキ、人が共有したレシピ、**対戦が終わった相手のデッキ**（ADR-0021）。どれも同じ操作で自分のデッキになる。

### 外で何が見えるか

- **ログインしていない人には、カード名と枚数と、作者が書いた解説まで出す。** 大会のデッキリストと同じ形で、レシピとして十分に通用する。
- **能力テキストと、その他の表記は、ログインした人にだけ出す。** レシピが数本たまれば、テキストまで出す口は**カード事典の公開**になる。ADR-0002 が避けているのはそれである。
- **興味を持った人には、入ってくるという道がある。** 共有の目的は「使ってみて」と渡せることなので、渡された人がもっと知りたくなったらログインすればよい。
- **未ログインに開く口は、識別子からカード名までである。** 総当たりすれば名前の一覧は抜ける。**それは許容する**——名前が出てよいと決めた以上、出る量を数える意味が無い。**テキストを返さない線だけを、その口で守る。**
- **作者を出す。名前は見るたびに引き直す。** 表示名はもともと人に見せるためのもので、本人が決めている（ADR-0020）。名前を変えれば、過去のレシピの表示も変わる。**共有した時点の名前を焼き付けるのは、そのための仕組みを作ってからにする。**

### 誰が出すか

- **公開ページは対戦サーバが出す。** レシピは同じマシンの置き場にあり（ADR-0018）、認証の要らない公開 HTTP の口はすでにある（ログインのコールバック、ADR-0019）。**新しい常駐物も新しい配り先も増えない。**
- **レシピから読めるものを作るところと、それを返すところを分ける。** 決まりごとと I/O を分けるのは `room.ts` と `serve.ts` が既にやっていることで、ここでも同じにする。**そうしておけば、共有したときに静的なものを書き出して配り先へ置く形（ADR-0013）へ、作り直さずに移せる。**
- **いまは対戦サーバが返し、いずれ静的に書き出す。** 公開のアクセスが常駐 1 台に来ることが重くなったら、そのとき移す。レシピは不変なので、**中継の側で作り置きが効く**うちは足りる見込みである。

## ここでは決めないこと

- **一覧の並べ方。** 新着か、コピーされた数か、その両方か。
- **解説に書けるものの長さと書式。**
- **共有した時点の作者名を焼き付ける仕組み。** 名前を変えても外のページが変わらないほうがよい場面はあるが、**それは別に作るものである。**
- **静的な書き出しへ移す時期。** 移せる形にしておくことだけを決めた。
- **同じレシピを何人が共有したときにどう見せるか。** 鍵が中身から決まるので、重なりうる。

## 影響

- **対戦サーバに、ログインしていない人が来るようになる。** SNS に貼られればクローラも来る。**いままで公開の口に来るのは、ログインの折り返しだけだった。**
- **表示名が、初めてゲームの外に出る。** これまで名前が見えるのは部屋にいる相手だけだった（ADR-0020、#186）。**本名である必要がないことは変わらないが、見える範囲は変わる。**
- **取り消しても、塞がらない穴が 1 つ残る。** 共有していないデッキも、対戦すれば相手に見えてコピーされる（ADR-0021）。**塞がない。** 当たったデッキを覚えて手で組み直すことは誰にでもできるので、塞いでも意味が薄い。
- **ADR-0002 が守っている線を、書き直すことになった。** 「公開リポジトリに置かない」と「誰にも見せない」は違う、というところを、あちらに書き足してある。
- **置き場に、持ち主が消しても残るものができる。** コピーされたデッキは別の人のものである。**元のレシピを取り消しても、コピーは残る。**
