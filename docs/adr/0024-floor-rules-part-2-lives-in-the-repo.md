# フロアルールの第2部の本文を公開リポジトリに置く

フロアルール（Version 1.12）の第2部（プロジェクト レヴォリューションに関する規定）の全文を `docs/floor-rules/` に置く。総合ルールに加えて、**この第2部も実装の拠り所になる。** 総合ルールは、デッキの規定のいくつかを「詳細はフロアルールをご参照ください」と外へ投げていて（第3部 第1章 3-1〜3-3）、その先がここにある。

ADR-0023 で、その先で決まっている判定はフロアルールの条を引いて実装すると決めた。引いた先の本文がリポジトリの外にあると、ADR-0007 が避けた「条番号からテストへ、テストからコードへ辿る導線が最初の一歩で切れる」状態が残る。総合ルールを置いた理由（ADR-0007）が、そのままフロアルールの第2部にも当てはまる。

ADR-0002 との関係も ADR-0007 と同じである。フロアルールは ＰＲＬＬＰ と ＤＰＡ が定めた公式文書で、ここでは実装の根拠として引用している。公開してよいことは開発者が判断した。カードの実装・能力テキストを公開しない線（ADR-0002）は動かさない。第2部の例には実在のカード名と型番が出てくるが、総合ルールの【例】にカード名が出てくるのと同じ扱いで、原文のまま置く。**禁止／制限リストの中身は第2部に書かれておらず、置いていない。**

## 決めたこと

- **置くのは、フロアルールのうち個別規定の第2部だけである。** 原文は「共通規定」（序文、第1部〜第4部。大会運営・反則と罰則を含む）と「個別規定」（第1部がディメンション・ゼロ、第2部がプロジェクト レヴォリューション）の 2 段になっている。ADR-0023 と引用の「第2部」は個別規定の第2部を指す。共通規定にも「第2部 大会運営に関する規定」があるが、それとは別物で、置かない。共通規定はこの実装が拠り所にしておらず、引用もされていない。必要になったときに別に置く。
- **置き場は `docs/floor-rules/`。形は `docs/rules/` と同じ**（章ごとに 1 ファイル、条番号は保存時に正規化、`index.json` に条の一覧）。総合ルールと混ぜない。索引を別にしておけば、総合ルールだけを数える走査が版の違う文書に巻き込まれない。
- **`index.json` の `citation` は、版まで含めた文字列にする。** 総合ルールは版が 1 つなので `第2部 第21章 1` だが、フロアルールは ADR-0023 で「フロアルール Version 1.12 第2部 第1章 1-1」の形に決めてあり、既存の引用がその形で書かれている。索引の文字列とコードに書く文字列を同じにして、そのまま引けるようにする。
- **丸括弧の段は、上の条の番号に `-` でつなぐ。** 第1章 3-4 の下の `(2-1)` は `3-4-(2-1)` と引く。原文の番号は `１．` `２，` `３－１.` `(2-1)` `（１）` が混在しており、条番号の正規化は ADR-0007 と同じ理由で保存時に行う。
- **本文の意味は変えない。** 直してよいのは抽出の誤りと条番号の表記だけで、要約・言い換えはしない（ADR-0007）。
- **引用が本文へ辿れることを、テストで守る。** コード・テスト・文書に書かれた「フロアルール Version …」の引用が、すべて `index.json` に見つかることを確かめる。

## 影響

- **拠り所の優先は変わらない。** 総合ルールが基本の拠り所（ADR-0007）で、フロアルールは総合ルールが外へ投げたところの拠り所（ADR-0023）である。本文を置いただけで、総合ルールとフロアルールが食い違って見えるときは、これまでどおり総合ルールが外へ投げたところかどうかで読み分ける。
- **第2部が指している共通規定は、辿れない。** 第2章は「共通項目『違反項目と罰則に関する規定』」を指すが、その先は置いていない。罰則の適用は実装していないので、いまは困らない。
- **第2部には、まだ実装していない規定が含まれる**（パートナーバトル、特定のエクスパンションだけを使える構築、ブースタードラフト、シールド、ペナルティ）。置いたのは文書であって、実装の約束ではない。
- **原文の PDF は文字コードが壊れていて、そのままではテキストにならない。** 復元した文字列を描画した画像と突き合わせ、本文と機械的に照合してある。行の折り返しで空白が読み取れない箇所が 1 つあり、文書の他の箇所に揃えた（`docs/floor-rules/README.md`）。
- **引用の形が 1 つ増えた。** 条に加えて丸括弧の段を引くとき（`3-4-(2-1)`）は、`index.json` にある形で書く。
