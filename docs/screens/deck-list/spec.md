# デッキ一覧の仕様

自分のデッキを並べて選ぶ画面と、デッキのラベルの決まりを書く。デッキを組むところは [`deck-builder/spec.md`](../deck-builder/spec.md)、全画面に共通する決まりとカードの面は [`shared/spec.md`](../shared/spec.md) にある。

**この文書が今の見た目の仕様の正である**（ADR-0044）。見本は同じディレクトリのモック [`index.html`](index.html)。モックには、まだ作っていない機能（自分で選ぶラベル・パートナーカードなど）も描いてある。

理由の記録: ADR-0028（見た目と並べ方）・ADR-0034（スマートフォン）。

## 並べ方（PC）

上に帯を 1 本置き、その下を 2 列に分ける。

- **上の帯**：「ロビーに戻る」、見出し、「自分の共有」「共有されたレシピ」「新しく作る」。
- **左の列**：
  - **デッキを探す**：デッキの名前で探す、入っている色、ラベル。ラベルは、複数選べば、どれかを持つデッキが残る。
  - **既製デッキからコピーして作る**。自分のデッキと同じく、表紙のカードを小さく添える（表紙のカード、名前、「コピーして組む」の順）。
    - 表紙のカードの選び方は自分のデッキと同じ（下の「表紙のカード」）。**既製デッキの中身は画面に届かないので、サーバが選んで、カードの識別子 1 つを `cover` としてロビーの既製デッキ（`WirePresetDeck`）に添える。** 選び方の決まりは engine の `deckCoverKeyOf` 1 か所に置く。パートナーカードを表紙のカードにする分（#228）が入るときは、決まりはここで足し、呼び出し側（サーバの既製デッキ・画面の自分のデッキ）がパートナーを渡す。
    - `cover` が付いていない時（表紙にできるカードが無い・古いサーバ）と、プールに無い識別子を指している時は、カードの裏面を出す。
- **右の列**：自分のデッキを、1 つずつカードの形で並べる。
  - **表紙のカード**：パートナーカードの面。未設定なら、一番多く入れたカード（同じ枚数ならレベルの高いもの）の面。パートナーカード（#228）が入るまでは、いつも後者である。
  - 名前、解説（2 行まで）、枚数、色ごとの枚数、ラベル。
  - 操作：編集・複製・共有・ラベル・削除。「ラベル」は、持ち主が選ぶラベル（#229）が入るまで出さない。

### 複製

自分のデッキを別のデッキとして保存し直す。

- 名前は、元の名前に「（コピー）」を付けたものにする。付けると名前の上限（40 文字。サーバと同じくコードポイントで数える）を超えるなら、**元の名前の末尾を削って、「（コピー）」込みで上限に収める。** 利用者は名前を打っていないので、サーバに長さで断られても何を直せばよいか分からないためである。削ったところが空白で終わるなら、その空白も落とす。
- 送るのは、`デッキを保存する` を `deck` 無しで送る形である（`デッキをコピーする` の `DeckOrigin` は既製デッキと共有レシピしか指せない）。サーバはこれを新しいデッキとして保存する。
- 保存できたら、そのまま複製したデッキを組むところを開く（既製デッキをコピーしたときと同じ）。
- **使えないカードが入っているデッキは、複製を押せない形にし、理由（使えないカードが入っていること）を画面と読み上げで添える。** サーバはプールに無いカードを含むデッキを保存しないため。

### 件数

- 件数に**上限を分母として**出さない。自分のデッキの数の上限は規則ではなく防御であり（ADR-0021）、画面にも届いていない。
- 一覧の見出しに「n / 全件数 件」のように、絞り込む前の件数を分母に出すのはよい。これは上限ではなく、いま持っているデッキの数である。
- 統計（デッキの数など）のパネルは置かない。

## ラベル

デッキに付く札を**ラベル**と呼ぶ。「タグ」は、属性を指すときに避ける語（CONTEXT.md）と紛れるので使わない。

- **自動で付くラベル**：デッキの中身を数えれば決まるものだけ。ルールの判断が要るもの（規定を満たすかなど）は付けない。
  - **アーキタイプ**：デッキの平均レベルから決める（アグロ・ミッドレンジ・コントロール）。平均が 3.6 以下ならアグロ、4.6 以上ならコントロール、その間はミッドレンジ。**この 2 つの値は仮の値で、実際のデッキを見て調整する。**
  - **色の構成**：単色なら「黒単」、2 色なら「赤黒」、3 色以上なら「多色」。**無色は色に含めない**（赤と無色だけなら「赤単」）。無色のカードだけのデッキには、色の構成のラベルは付かない。
  - 使えないカード（プールに無いカード）は、印刷されている項目が分からないので数えない。使えないカードだけのデッキには、自動のラベルは付かない。
  - **主な作品名・ブロック**：半分以上を占めるものがあれば付く。
- **持ち主が選ぶラベル**：決まった選択肢から選ぶ。#229 で作り、それまでは画面に出さない。
  - **アーキタイプ**（1 つまで）：アグロ・ミッドレンジ・コントロール・コンボ。**選んでいれば、自動のアーキタイプは付けない**（選んだ人の判断を優先する）。
  - **その他**（いくつでも）：初心者向け・大会用・お試し。
- **見た目は 1 つ。** 自動で付いたか選んだかを、見た目にも、ホバーにも、読み上げにも出さない。読み上げは「アーキタイプ：ミッドレンジ」のように、分類と中身を伝える。
- **中身を表す絵文字を先頭に付ける**（アグロ ⚡・ミッドレンジ ⚖️・コントロール 🛡️・コンボ 🧩・初心者向け 🔰・大会用 🏆・お試し 🧪・作品名 📖・ブロック 🏢・多色 🌈）。色の構成は色のアイコンで表す。
- **付け外しは 2 か所から。**
  - デッキを組むところの帯の「ラベル」：組みかけに入る。保存するまで残らない（解説と同じ）。
  - デッキの一覧の各デッキの「ラベル」：「やめる」「保存する」を置き、その場で保存する。

## スマートフォン（幅 768px 以下）

1 列に縦に積む。上から、見出しとボタン（折り返す）、絞り込み（畳んでおき、押すと開く）、自分のデッキの並び（1 列）、既製デッキからコピーする欄。

- **Tab と読み上げの順も、この見た目の順にそろえる。** PC では既製デッキの欄が左の列の下にあり、DOM もその順なので、スマートフォンの幅のときだけ DOM の順を入れ替える（CSS の `order` で見た目だけを並べ替えない）。
- デッキを消す確認・変更を捨てる確認・共有の窓は、幅いっぱいに出す。ボタンの高さは 2.75rem 以上、入力欄の文字は 16px にする。

## 持たないもの

- デッキごとの公開中／非公開の印と、公開の状態での絞り込み。そのために要る共有とデッキの紐付けも持たない（自分の共有 `WireShare` は、どのデッキから出したかを持たない）。
